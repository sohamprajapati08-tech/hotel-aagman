4-Step Google Drive & Sheets Setup Guide

Follow these 4 simple steps to save your live hotel data directly to Google Drive

Step 1: Create a New Google Sheet

Open Google Drive or visit sheets.new to create a new sheet titled "Hotel Aagaman Live Database".

Step 2: Extensions > Apps Script

In your Google Sheet top menu, select Extensions and then click Apps Script.

Step 3: Paste Webhook Script

Replace existing code with the ready-made script below and press Save (Ctrl+S).

Step 4: Deploy as Web App

Click Deploy > New deployment > Select type Web app > Set Who has access: Anyone > Deploy and paste the resulting URL above.
